# Photographic source catalog

This is a discovery catalog of 10,000 source-linked photographic records from the Metropolitan Museum of Art and the Library of Congress. Only metadata and links are stored here. Opening the homepage does not download this catalog.

Institutional record IDs are unique. Different records or versions may depict the same photograph. The catalog is not a claim that every entry is visually reviewed, suitable for this page, or cleared for every use.

A record's source rights claim is evidence to investigate, not permission to publish. Before a photograph enters an active collection, its source, author, date, exact image, rights and full composition must be checked. Uncertain entries stay out. The last checked collection stays live if a new collection fails review.

Sources:
- https://github.com/metmuseum/openaccess/blob/master/MetObjects.csv
- https://www.metmuseum.org/policies/image-resources
- https://www.loc.gov/apis/json-and-yaml/

## Publication

The old automatic harvester and picker are disabled. There is no unattended candidate-to-homepage publication step. Active images must come from an explicitly reviewed collection, use immutable content-addressed filenames and include the required source and license credits.
